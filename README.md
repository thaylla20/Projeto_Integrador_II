# ConectaMente

## 1. Apresentação do projeto

O ConectaMente é um projeto desenvolvido para o Projeto Integrador II do Curso Técnico de Informática.

A proposta é criar um espaço digital para facilitar a comunicação entre estudantes que possuem dúvidas e estudantes que podem ajudar em determinadas matérias.

O sistema busca tornar o processo de estudo mais simples, acessível e colaborativo, permitindo que os próprios alunos compartilhem conhecimentos e recebam ajuda.

---

## 2. Problema identificado

Durante as aulas, alguns estudantes possuem dúvidas, mas podem deixar de perguntar por vergonha, medo de errar ou dificuldade para falar na frente da turma.

Quando essas dúvidas não são esclarecidas, elas podem se acumular e dificultar os estudos, principalmente antes das avaliações.

Por isso, surgiu a ideia de criar uma plataforma que facilite a busca por ajuda entre os próprios estudantes.

---

## 3. Solução proposta

O ConectaMente permite que um estudante publique uma dúvida informando a matéria e descrevendo o que precisa entender.

Um monitor pode visualizar as dúvidas disponíveis, aceitar um atendimento e combinar um horário para ajudar o estudante.

Após o atendimento, o estudante pode confirmar que recebeu a ajuda e realizar uma avaliação.

A proposta é incentivar a colaboração entre os alunos e facilitar o acesso à ajuda escolar.

---

## 4. Objetivos

### Objetivo geral

Criar um protótipo de uma plataforma de apoio entre estudantes, facilitando a publicação de dúvidas e a realização de atendimentos de monitoria.

### Objetivos específicos

- Facilitar a publicação de dúvidas escolares.
- Permitir que monitores visualizem solicitações de ajuda.
- Possibilitar o aceite de atendimentos.
- Permitir o agendamento dos atendimentos.
- Disponibilizar uma agenda para acompanhamento.
- Possibilitar comunicação por meio de um chat.
- Permitir a confirmação e avaliação do atendimento.
- Disponibilizar um painel para acompanhamento pela coordenação.

---

## 5. Público-alvo

O projeto possui três principais tipos de usuários:

### Aprendiz

É o estudante que possui uma dúvida e procura ajuda em determinada matéria.

### Monitor

É o estudante que possui conhecimento em uma ou mais matérias e pode ajudar outros alunos.

### Coordenação

É o usuário responsável pelo acompanhamento dos atendimentos realizados pelos monitores.

---

## 6. Principais funcionalidades

O protótipo possui as seguintes funcionalidades:

- Login por tipo de usuário.
- Publicação de dúvidas.
- Seleção da matéria.
- Visualização de dúvidas.
- Aceitação de atendimento pelo monitor.
- Agendamento de atendimento.
- Visualização da agenda.
- Chat interno.
- Confirmação do atendimento.
- Avaliação do atendimento.
- Seleção das matérias que o monitor domina.
- Painel da coordenação.

---

## 7. Tecnologias utilizadas

O protótipo foi desenvolvido utilizando:

- HTML para a estrutura das páginas.
- CSS para a aparência e organização da interface.
- JavaScript para implementar as funcionalidades e interações.
- GitHub para armazenamento, organização e acompanhamento do projeto.

---

## 8. Execução do protótipo

Para executar o protótipo, basta abrir o arquivo:

`src/index.html`

em um navegador de internet.

O sistema funciona como um protótipo local e utiliza o armazenamento do navegador para manter algumas informações durante a utilização.
